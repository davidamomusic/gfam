## What this repository contains, and what it does not

- **No Nintendo material.** No BIOS, no game, no SDK or library code (no devkitPro, no libgba), no other program's code, and **no
  Nintendo logo**. The code in `src/` and `tools/` was written for this project. The tiles, palette and tables are generated by
  `tools/gen_assets.py`, and the font in `tools/font.py` is drawn glyph by glyph in the file itself.
- **The ROM has an empty logo field.** A GBA ROM has room in its header (bytes `0x04` to `0x9F`) for the Nintendo logo, which the real
  BIOS checks before it starts a program. That logo is Nintendo's, so the ROM in [`releases/`](releases/) leaves the field at zero, and
  `tools/fix_header.py` does not contain it. `sh tools/run_tests.sh` fails if a ROM in `build/` or `releases/` has anything in that field.
- **What the ROM does hold from outside**: nothing but the header fields every GBA program has (title `GFAM`, game code `ZGFM`, a version
  byte and the header checksum), which are my own values.
- **For your own device**, `make LOGO_FROM=file.gba` copies the logo field from a GBA ROM that you already own, so a real BIOS accepts
  the build. That is a step you take on your own computer, for your own use. Please do not publish a ROM made that way.
